# 🚀 Nombre de tu Proyecto

Este es el Frontend de mi aplicación cuyo objetivo es la gestión de incidencias relacionadas con el internet (WIMAX o FTTH), creación y gestión de clientes y sus servicios, además de crear y gestionar los usuarios (trabajadores) que se van a encargar de las diferentes gestiones.

## 🛠️ Tecnologías
- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## 📦 Instalación

1. `git clone https://github.com/APA1112/frontend.git`
2. `npm install`
3. `npm run dev`
